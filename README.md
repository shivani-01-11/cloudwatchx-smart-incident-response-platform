# CloudWatchX — Smart Incident Response Platform

CloudWatchX is an event-driven AWS observability and incident response platform designed to simulate real-world operational telemetry pipelines.

## Current Features

- Local incident simulator
- AWS EventBridge integration
- Lambda incident processing
- DynamoDB operational persistence
- CloudWatch custom metrics
- Operational dashboards
- SNS alerting

## AWS Services Used

- EventBridge
- Lambda
- DynamoDB
- CloudWatch
- SNS
- IAM

## Architecture

Local Generator → EventBridge → Lambda → DynamoDB → CloudWatch → SNS

Project currently under active development.
